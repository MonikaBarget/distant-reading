# Distant Reading Testing Repository

I (@MonikaBarget) started this repository in 2022 to give students taking courses in computational text analysis at Maastricht University better access to code, data samples and short instructions.

In 2025/2026, an OpenUp grant awarded by the University Library in Maastricht allowed me to transform this repository into an [interactive textbook](https://maastrichtuniversitypress.github.io/distant-reading-textbook/main/intro.html) with live coding embedded, hosted via Maastricht University Press.

Please consult the new repository and deployment! Files kept here are for testing purposes only.
